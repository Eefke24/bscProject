# bscProject
Experiment code for my bachelor thesis regarding 'An Investigation of the Immediate Effects of Mindfulness Meditation on Mental Stress Using Wearable Electroencephalography'.

This stress-inducing experiment is based on the aforementioned Montreal Imaging Stress Task (MIST) (Dedovic et al.,2005). 
The experiment consisted of three MISTs (baseline, S1 and S2). Each MIST contains five active blocks and five rest blocks. 
Each active block has a duration of 30 seconds and each rest block has a duration of 20 seconds. 
During the active blocks, equations containing three one-digit integers (ranging from 1 to 9) were presented to the participants.
Operators were limited to subtractions (‘-’) and addition (‘+’). 
The S1 and S2 were identical to each other. In contrary to the baseline, participants were put under stress by adding various stressors to the task.
